# The licences that the Python packages of the Docker image may be under (Story 34.2; owner answer U-285, 2026-11-05).
# They cover the transitive set of fastembed 0.9.0, pdfplumber 0.11.10 and python-docx 1.1.2 only. gate.py reads this file and
# nothing else; the image build fails on a distribution whose licence is not covered here. ASCII only.
#
# Lines:
#   allow <identifier>            a licence the gate accepts, by SPDX identifier (matched without regard to case)
#   alias <declared text> = <id>  a licence as a package declares it (the License field or a classifier), read as <id>
#   text <id> :: <regex>          a licence file that holds this text is read as <id>; the regex is matched against the
#                                 file's text in lower case, quotes straightened and white space collapsed
#   ignore <phrase>               a declared phrase that is not a licence name (pypdfium2 says "dependency licenses" for
#                                 the PDFium libraries it bundles); a distribution that declares it passes only when every
#                                 licence file it ships is read as an allowed licence
#   docs <identifier>             a licence for documentation only: a licence file that holds its text counts as allowed,
#                                 but a package that declares it fails
# Every declaration of a package counts (its License-Expression, its License and each License classifier), and each must be
# allowed. A declaration that names a licence outside the allow lines fails, whatever files the package ships, unless an OR
# gives an allowed alternative; a phrase is never the alternative that rescues it. A package that declares nothing passes
# only through its licence files. OR means a dual licence: one alternative that is allowed is enough (so FreeType's GPL
# option is never needed and never taken: the FTL is the alternative that counts).
